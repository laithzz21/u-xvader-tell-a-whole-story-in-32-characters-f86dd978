# Tell a Whole Story in 32 Characters

A single Wi-Fi network name, at most 32 characters, that lands a joke and implies a whole story.

## Entry

```
My Ex Changed The Password
```

26 characters. A break-up told through the Wi-Fi: somebody moved out, somebody stayed, and the password changed — no long explanation needed, just a locked-out ex and a router that picked a side.

## Run

```sh
python3 main.py
```

Prints exactly the entry text to stdout and nothing else.
